# 🏆 Платформа для подготовки к олимпиадам

**Краткое описание проекта:** Интерактивный веб-сервис для учащихся школы №1518, предназначенный для подготовки к олимпиадам. Система сочетает классическое решение задач и уникальный PvP-модуль для соревнований между учениками в реальном времени.

## 🎞 Видео-демонстрация
[Смотреть обзор проекта на Rutube](https://rutube.ru/video/private/37d853af8d17da84219491da28392dd0/?p=UKvcKUgqg03X6ZelgNSrZg)

## 🚀 Функциональность

### Для ученика:
* 🔐 **Авторизация:** Безопасный вход в систему.
* 🧩 **Тренировка:** Решение задач трех уровней сложности (Easy, Medium, Hard).
* ⚔️ **PvP-дуэли:** Создание комнат и соревнование с оппонентом на скорость решения.
* 📈 **Профиль:** Отслеживание личного рейтинга и статистики побед.

### Для администратора (через Django Admin):
* ➕ **Управление контентом:** Добавление, редактирование и удаление олимпиадных задач.
* 👥 **Контроль пользователей:** Управление учетными записями и обнуление рейтинга при необходимости.
* 📊 **Мониторинг:** Просмотр активных игровых сессий.

## 🛠 Технологический стек

### Бэкенд:
* **Python Django:** Основной каркас приложения, маршрутизация и логика.
* **Django ORM:** Работа с базой данных и построение запросов.
* **Django Auth:** Система управления сессиями и правами доступа.

### Фронтенд:
* **JavaScript (Vanilla):** Логика таймеров и динамическое взаимодействие в PvP.
* **HTML/CSS + Django Templates:** Адаптивная верстка и шаблонизация страниц.
* **AJAX:** Отправка ответов и получение результатов без перезагрузки страницы.

### База данных:
* **PostgreSQL:** Надежное хранение данных пользователей, задач и результатов матчей.

## ⚙️ Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone [https://github.com/](https://github.com/)[ВАШ_РЕПОЗИТОРИЙ]
   cd OlimpiadPlatform-main
2.Настройка окружения:
	python -m venv .venv
	# Активация для Windows:
	.venv\Scripts\activate
3.Установка зависимостей:
	pip install -r requirements.txt
4.Миграции и запуск:
	python manage.py migrate
	python manage.py runserver
